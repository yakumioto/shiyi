# 登录会话可以持久化，但不是记忆

为支持单用户多设备登录、重启后保持登录及服务端撤销，允许独立持久化登录会话与必要的认证控制状态；这些状态不写入记忆分片、不参与检索，也没有证据资格。此决策限定 [ADR 0006](<0006-only-records-are-persisted.md>) 中“只持久化记录”和“重启后没有任何会话状态”的适用范围：查询、回答与对话上下文仍不持久化，[ADR 0001](<0001-jsonl-as-sole-source-of-truth.md>) 中记录 JSONL 作为记忆唯一真相源的约束保持不变。选择持久化且可撤销的认证状态，而非每次重启强制重新登录或只靠长期无状态凭据，是为了同时满足使用连续性与设备失控后的访问回收；代价是增加独立认证状态的权限、恢复和失效管理，本决策获准实施但不表示当前代码已提供登录。
