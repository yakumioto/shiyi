# 模型可用性不决定认证可用性

新增 Web 登录后，模型网关故障不能阻止用户登录、检查登录会话、退出当前设备或撤销所有设备的访问，因此认证与存活检查不得调用模型或依赖模型连通性。此决策限定 [ADR 0005](<0005-service-availability-follows-model.md>) 中“整个服务不可用”的范围为依赖模型的分类与回答操作：模型失败时仍明确报错，不绕过分类写入记录，也不新增离线问答或后台排队。相较于将所有入口统一绑定模型健康，分离控制访问与处理记忆的可用性可以保留故障期间的安全操作，但必须分别描述存活、认证和模型业务是否可用；本决策获准实施，不表示当前代码已有登录能力。
