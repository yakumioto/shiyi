# 07: 冻结测试集与 CI

**What to build:** 维护者能在不调用真实模型的情况下验证分类、检索、引用、预算和失败路径；冻结用例一旦发布就不能被悄悄修改，篡改会让测试失败。真实模型评测独立运行，不阻塞 CI。

**Blocked by:** 03 (多轮检索与检索预算), 04 (失败与持久化边界).

**Status:** ready-for-agent

- [x] 冻结目录包含分类、查询、预算与失败路径用例，以及每个文件的 SHA-256 清单。
- [x] 测试用假 LLM 覆盖记录、查询、无法识别、无结果、预算耗尽、非法引用、模型不可用。
- [x] 修改或删除冻结文件后，测试失败并指出具体文件。
- [x] `go test ./... -race`、`go vet ./...` 与冻结集在无网络环境全部通过。
- [x] 真实模型评测脚本可独立运行，不进入 CI 门禁。
- [x] 新增用例进入新版本目录，测试同时跑所有已冻结版本。
