# 06: Web：极简浏览器界面

**What to build:** 用户打开首页就能发送一句话，看到它被记录，或看到带引用的回答；界面只呈现当前会话，不保存历史。模型输出按纯文本显示，不能执行脚本。

**Blocked by:** 02 (查询路径).

**Status:** ready-for-agent

- [ ] 首页能发送记录并显示记录时间。
- [ ] 首页能发送查询并显示回答、状态与引用原文。
- [ ] 回答或原文中的 HTML/脚本不会被执行。
- [ ] 刷新后不保留任何历史。
- [ ] 无外部 CDN、无遥测、窄屏可用。
- [ ] 手工冒烟覆盖记录、查询、无法识别与错误提示。
