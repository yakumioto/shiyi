# 01: 记录路径：一句话变成一条记录

**What to build:** 用户能通过一个 HTTP 请求把一句话交给 Shiyi；被判定为记录时，原文立即成为一条可检索的记忆，响应返回记录时间；被判定为无法识别时，明确告诉用户没有保存。这个切片打通配置、分类、记录存储与记录入口，是后续所有切片的地基。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 服务能按配置的模型地址、模型名和密钥环境变量启动，`GET /healthz` 返回 200。
- [ ] `POST /messages` 收到一条被判定为记录的消息时返回 201，响应包含 `kind:"record"`、`version:1` 和 `time`。
- [ ] 数据目录新增一行 JSONL，字段恰好为 `version`、`content`、`time`；`content` 与提交原文逐字一致。
- [ ] 连续提交两条记录，产生的 `time` 严格递增且互不相同。
- [ ] 收到无法识别的消息时返回 200，数据目录不新增任何行。
- [ ] 分类模型返回非法内容或调用失败时，本次不写文件，并返回明确错误。
- [ ] 查询路径尚未实现时返回明确的未实现错误，且不写文件；查询行为在 02 补齐。
- [ ] 测试使用假 LLM 覆盖记录、无法识别和不落盘路径，可在无网络环境运行。
