# 05: CLI：命令行记录与查询

**What to build:** 用户能在终端里一句话记录或提问，看到记录时间、回答、状态与引用；也能进入交互式会话连续使用，或启动本地服务。错误以非零退出码返回，便于脚本判断。

**Blocked by:** 02 (查询路径).

**Status:** ready-for-agent

- [x] `shiyi "..."` 能完成一次记录并打印记录时间。
- [x] `shiyi "..."` 能完成一次查询并打印回答、状态与引用原文。
- [x] `shiyi` 进入 REPL，每条输入独立发送，`/quit` 退出。
- [x] `shiyi serve` 能启动服务。
- [x] 服务返回 4xx/5xx 时打印错误码与信息，并以非零退出码结束。
- [x] 测试覆盖参数解析与响应格式化；不依赖真实模型。
