# 08: 容器与使用文档

**What to build:** 用户能用容器运行 Shiyi，把数据目录挂载到宿主机；升级或重启容器后记录仍在。README 能让人从零完成一次记录和一次查询，并说明配置、鉴权、健康检查与已知限制。

**Blocked by:** 04 (失败与持久化边界), 05 (CLI), 06 (Web).

**Status:** ready-for-agent

- [ ] 容器镜像构建成功，运行环境内 `rg --version` 可执行。
- [ ] 挂载数据卷后，重启容器记录仍然存在。
- [ ] 按 README 的命令能完成一次记录和一次查询。
- [ ] 配置示例覆盖模型、数据目录、分片、鉴权与预算，密钥只通过环境变量提供。
- [ ] 健康检查在容器内返回 200。
- [ ] README 明确列出已知限制：无回答持久化、无幂等、无会话上下文、不支持附件、跨换行检索限制。
