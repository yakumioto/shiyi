# 03: 多轮检索与检索预算

**What to build:** 复杂问题可以让 LLM 连续检索多次，但总检索次数、读取记录数和耗时都有上限；预算耗尽时返回已有证据支撑的部分回答并明确标注状态，而不是挂起或编造。跨轮引用仍然只能指向实际检索到的记录。

**Blocked by:** 02 (查询路径).

**Status:** ready-for-agent

- [ ] 模型可以连续调用检索工具，最多 3 次；每次返回不超过剩余可读记录数。
- [ ] 总读取记录数不超过 20 条，回答阶段总时长不超过 30 秒。
- [ ] 超过任一预算时停止检索，用已有证据做一次不带工具的最终回答，状态为 `budget_exhausted`。
- [ ] `budget_exhausted` 的回答仍只引用本次检索返回过的记录；非法引用返回 502。
- [ ] 跨轮合法引用能正常返回；跨轮引用未检索记录被拒绝。
- [ ] 测试使用假 LLM 覆盖多轮、预算耗尽和跨轮非法引用。
