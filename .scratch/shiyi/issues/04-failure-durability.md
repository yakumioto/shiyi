# 04: 失败与持久化边界

**What to build:** 当模型不可用、输入非法、文件损坏或配置改变分片粒度时，用户得到明确结果，记录不会被静默污染或丢失。模型失败时本次输入不保存；崩溃留下的半行被隔离；中间损坏让服务拒绝启动而不是装作正常。

**Blocked by:** 02 (查询路径).

**Status:** ready-for-agent

- [ ] 模型不可达、超时或返回非法分类/回答时返回 503，数据目录不新增行。
- [ ] 空内容返回 400；超过请求体上限返回 413；启用 Bearer 后缺失或错误 token 返回 401。
- [ ] 模拟最后一行不完整：服务启动成功，坏尾被移动到隔离位置，之前的记录仍可读。
- [ ] 模拟中间行损坏：服务启动失败，错误信息指出位置，不静默丢数据。
- [ ] 分片配置为按月、按周、按天时，记录进入对应分片，跨边界行为正确。
- [ ] 存储失败与检索失败分别返回 500 的明确错误码，不泄露模型原始错误。
- [ ] 测试覆盖上述路径，可在无网络环境运行。
