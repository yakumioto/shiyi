# 02: 查询路径：从记录中检索并带引用回答

**What to build:** 用户先记录事实，再提出一个问题；Shiyi 能在记录中做字面检索，让 LLM 基于命中记录生成回答，并把每条依据以「记录时间 + 原文」返回。没有命中时明确说没有找到，而不是凭常识回答。查询不写任何文件。

**Blocked by:** 01 (记录路径).

**Status:** ready-for-agent

- [ ] 先记录两条事实，再提交查询，返回 200、`kind:"query"`、`status:"ok"`，回答内容来自记录。
- [ ] 每个引用都包含 `time` 和 `content`，且 `time` 与已写入记录一致。
- [ ] 没有命中时返回 `status:"no_match"`，回答为固定的「没有找到相关记忆」，引用为空。
- [ ] 查询前后数据文件内容完全不变。
- [ ] 模型引用本次检索未返回的记录时，返回 502 `invalid_citation`，不返回回答。
- [ ] 本切片只支持一次检索调用；多轮检索在 03 补齐。
- [ ] 测试使用假 LLM 覆盖命中、无命中、非法引用，可在无网络环境运行。
